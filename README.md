# nichive - цифровой архив моды

Многостраничный сайт для итоговой междисциплинарной КТ4 (Веб-дизайн · Фронтенд · Tilda/Blender).
Концепция: цифровой музей, который выставляет **один объект моды в месяц**. Текущий экспонат - **Object N°03, Maison Margiela Tabi**.

## Стек
- HTML5 (семантика, единый header/nav на всех страницах, SEO-теги)
- CSS3 (адаптивный дизайн, единая дизайн-система, mobile-first медиазапросы)
- JavaScript (интерактивное бургер-меню, слайдер на главной, прокрутка-вращение 3D)
- **Three.js r160** - интерактивная 3D-визуализация, импорт собственных моделей

## Страницы
- `index.html` - Object N°03: hero с интерактивной 3D-моделью (вращение по прокрутке и перетаскиванию), слайдер историй, архив, подписка
- `exhibitions.html` - архив выставок + **интерактивная 3D-галерея** (OrbitControls, переключение между 6 моделями)
- `stories.html` - фоторепортаж «день с объектом»
- `manifesto.html` - принципы платформы
- `materials.html` - производственная цепочка
- `subscribe.html` - форма подписки с JS-валидацией

## 3D-модели (`/models`, формат .glb с текстурами)
1. `tabi.glb` - раздвоенный ботинок (главный экспонат) · 3 текстуры
2. `perfume.glb` - флакон · текстура
3. `pedestal.glb` - музейный постамент · 3 текстуры
4. `scissors1.glb`, `scissors2.glb` - инструменты ателье · 3 текстуры каждый
5. `dressform.glb` - портновский манекен · материал

Модели оптимизированы для веба (gltf-transform: meshopt + WebP-текстуры).

## Дизайн
Макет разработан в Figma (ссылка в кейсе). Палитра: кремовый `#EFEAE2`, чернила `#0A0A0A`, ржавый акцент `#9C3A2B`. Шрифты: Inter + JetBrains Mono.

## Запуск
Локально: `python -m http.server` в корне → открыть `http://localhost:8000`.
(нужен HTTP-сервер - ES-модули и загрузка .glb не работают через `file://`)

## Что сделано с ассистентом ИИ (Claude) - честно

Дизайн, концепция, контент, 3D-модели (импорт/правка в Blender), структура и сборка - мои.
С ассистентом ИИ реализованы технически сложные части (см. `colophon.html` на сайте):

- **Three.js hero** - авто-фит камеры через радиус ограничивающей сферы и тригонометрию FOV, связка scroll/drag/idle вращения (`js/three-hero.js`)
- **Three.js галерея** - OrbitControls с зумом, центрирование моделей, сцена с двумя моделями ножниц, MeshoptDecoder (`js/three-gallery.js`)
- **Оптимизация 3D** - пайплайн gltf-transform (meshopt + WebP), сжатие 80 МБ → 3.3 МБ
- **Процедурный ASCII-арт** - синусоидальное поле плотности → рампа `░▒▓█` (`js/main.js`)
- **Хореография подписки** - зачёркивание строк → растворение → пошаговая сборка плашки
- **Сборка по скроллу** - IntersectionObserver + каскадные cubic-bezier переходы
